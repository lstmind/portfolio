# 007 — Смягчить смену фильтра в индексе работ

- **Status**: DONE
- **Commit**: 2023bf2
- **Severity**: LOW
- **Category**: Missed opportunity
- **Estimated scope**: 2 файла, ~20 строк

## Problem

`components/WorksIndex.tsx:13` — список пересобирается синхронно, без единого кадра перехода:

```tsx
// components/WorksIndex.tsx:13 — current
const items = cat === "Все" ? WORKS_INDEX : WORKS_INDEX.filter((w) => w.cat === cat);
const shown = all ? items : items.slice(0, PREVIEW);
```

Человек жмёт чип «Боты» — строки телепортируются: часть исчезает, часть подставляется на чужие места, номера `01, 02, 03` перенумеровываются под теми же заголовками. Ровно тот случай, ради которого движение и существует: не украсить, а не дать содержимому прыгнуть.

Это единственный интерактивный список на сайте, который меняет состав по клику. Секция `.widx` при появлении уже едет через `.reveal` (`app/globals.css:134`), то есть язык входа в проекте задан — а при смене фильтра он не используется.

## Target

Строки списка входят с той же кривой, что и остальной сайт, коротким стаггером:

```css
/* target — app/globals.css, рядом с .widx-list */
.widx-list a{animation:wrow .34s var(--ease-out) both}
@keyframes wrow{from{opacity:0;transform:translateY(6px)}}
@media (prefers-reduced-motion: reduce){.widx-list a{animation:none}}
```

```tsx
// target — components/WorksIndex.tsx, в разметке ссылки
<a
  key={w.href}
  style={{ animationDelay: Math.min(i, 8) * 40 + "ms" }}
  ...
>
```

- 340мс и `var(--ease-out)` — вход, значит `ease-out` (токен вводится планом 006).
- Стаггер 40мс, обрезанный на восьмой строке: при 20+ элементах ждать 800мс до последней строки нельзя, а первые восемь дают ощущение волны.
- `both` нужен, чтобы строка не мигала до старта своей задержки.
- Ключ `key={w.href}` уже уникален по элементу, поэтому React пересоздаёт узлы при смене фильтра и анимация перезапускается сама, без ручного сброса.

Стаггер здесь декоративный и не должен блокировать взаимодействие: ссылки кликабельны с первого кадра, `pointer-events` не трогаем.

## Repo conventions to follow

- Кейфреймы объявляются сразу под правилом, которое их использует, например `@keyframes scroll` под `.marq .track` (`app/globals.css:109`).
- Имена кейфреймов короткие и без префиксов: `fade`, `rise`, `ride`, `scroll`, `pp` — новое имя `wrow` в том же духе.
- Все анимации глушатся в блоке `@media (prefers-reduced-motion: reduce)` (`app/globals.css:426`) — добавить туда же, а не отдельным медиазапросом, если так выйдет компактнее.

## Steps

1. Выполнить план 006 (нужен токен `--ease-out`) либо подставить `cubic-bezier(.16,1,.3,1)` литералом.
2. `app/globals.css` — добавить правило `.widx-list a{animation:...}` и `@keyframes wrow` сразу под ним.
3. `app/globals.css:426` — дописать `.widx-list a{animation:none!important}` в блок reduced-motion.
4. `components/WorksIndex.tsx:44` — добавить `style={{ animationDelay: ... }}` в ссылку.

## Boundaries

- НЕ менять логику фильтрации, `PREVIEW` и кнопки «Показать ещё» / «Свернуть».
- НЕ добавлять библиотеку анимаций ради этого — задача решается кейфреймом.
- НЕ анимировать высоту контейнера списка: строки разной высоты, скачок контейнера заметнее, чем польза.
- НЕ трогать `.widx .chip` — состояние чипа уже анимировано корректно.

## Verification

- **Механически**: `npx tsc --noEmit` — чисто.
- **Проверка на глаз**:
  - переключить чип: строки проявляются волной сверху вниз, ни одна не мигает белым;
  - быстро прощёлкать четыре чипа подряд — нет наложения двух списков и нет застрявших полупрозрачных строк;

  - кликнуть по строке в первый же кадр после смены фильтра — ссылка открывается.
- **Готово когда**: смена фильтра не даёт ни одного кадра, где строка появляется на чужом месте без перехода.
