## Problem

Состояние отправки у формы **есть** и сделано верно — `components/ContactForm.tsx:75`:

```tsx
// components/ContactForm.tsx:75 — current
<button className="submit" data-cursor data-magnet disabled={status === "sending"}>
  {status === "sending" ? "Отправляю…" : "Отправить заявку →"}
</button>
```

Кнопка блокируется, текст меняется, `form .submit:disabled{opacity:.6}` даёт визуальный отклик. Претензий нет.

Не хватает другого: результат появляется телепортом.

```tsx
// components/ContactForm.tsx:78 — current
{status === "ok" && <div className="formok">Заявка ушла — отвечу в течение часа. Спасибо!</div>}
{status === "error" && (
  <div className="formok">Не отправилось. Напишите напрямую в ...</div>
)}
```

`.formok` (`app/globals.css:373`) не имеет ни анимации, ни перехода: строка возникает под кнопкой мгновенно и сдвигает вниз примечание «Заявка придёт мне в Telegram».

Это самый редкий и самый заряженный момент на сайте — человек только что решился написать. По каталогу редкие первые события как раз и есть то место, где бюджет на движение можно тратить, и единственное на всём сайте, где он не потрачен вообще.

Тот же телепорт у сообщения о невалидном контакте (`ContactForm.tsx:64`), там он к тому же с `role="alert"`.

## Target

```css
/* target — app/globals.css, рядом с .formok */
.formok{font-family:var(--font-mono);font-size:13px;color:var(--acc);animation:formin .3s var(--ease-out) both}
@keyframes formin{from{opacity:0;transform:translateY(-4px)}}
```

Сдвиг **вверх на 4px**, а не вниз: сообщение выезжает из-под кнопки, которая его породила, а не падает сверху. Пространственная связь с источником.

300мс и `var(--ease-out)` — вход. Токен вводится планом 006; без него подставить `cubic-bezier(.16,1,.3,1)`.

В блок `@media (prefers-reduced-motion: reduce)` (`app/globals.css:426`) добавить `.formok{animation:none!important}` — сообщение об ошибке несёт смысл и должно появляться мгновенно, без ожидания кадров.

## Repo conventions to follow

- Кейфреймы объявляются под своим правилом и называются коротко: `fade`, `rise`, `ride`, `pp` (`app/globals.css:78, 82, 224`).
- Все анимации перечислены в блоке reduced-motion на строке 426 — добавить туда же.
- `.formok` используется тремя разными сообщениями (успех, ошибка, невалидный контакт) — правило на классе покрывает все три, отдельные не нужны.

## Steps

1. Выполнить план 006 либо подставить кривую литералом.
2. `app/globals.css:373` — дописать `animation:formin .3s var(--ease-out) both` в `.formok`.
3. Сразу под ним объявить `@keyframes formin`.
4. `app/globals.css:426` — добавить `.formok{animation:none!important}` в блок reduced-motion.

## Boundaries

- НЕ трогать логику отправки, валидацию и `ymGoal("lead_form")`.
- НЕ добавлять спиннер: текст «Отправляю…» уже сообщает состояние, спиннер здесь дублирует.
- НЕ анимировать саму кнопку при переходе в `disabled` — `opacity:.6` достаточно.
- НЕ менять тексты сообщений.
